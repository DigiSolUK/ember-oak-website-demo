# Restaurant Sample Site (Local Launch)

This is a static multi-page sample website with the required pages:

- Home (`index.html`)
- About Us (`about.html`)
- Menu (`menu.html`)
- Banquet Facility (`banquet.html`)
- Gallery (`gallery.html`)
- Catering (`catering.html`)
- Contact Us (`contact.html`)
- Visiting Hours (`visiting-hours.html`)
- Online Booking (`online-booking.html`)
- Menu Kit (`menu-kit.html`)

## Launch locally

From this folder:

```bash
python3 -m http.server 8080
```

Open in browser:

- http://localhost:8080/index.html

## Notes

- No shopping cart is included.
- Forms are demo-ready and currently show confirmation messages on submit.
- Replace text, photos, and downloads with final client branding/content.
